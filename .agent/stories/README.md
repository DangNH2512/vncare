# User Story

Mỗi story một file, đặt tên `<sprint>-<số>-<mô-tả-ngắn>.md`, ví dụ
`1-1-event-list-area-filter.md`. Dùng khuôn ở
[`.agent/templates/story-template.md`](../templates/story-template.md).

Story bắt nguồn từ use case trong `docs/analysis/02-use-case.md` và kế hoạch sprint
trong `docs/analysis/08-roadmap-va-ke-hoach-trien-khai.md`.
